## 1. Footage & Visual Asset Providers

### A. Pexels Stock Video API
- **Provider:** Pexels GmbH / Canva
- **API Endpoint:** `https://api.pexels.com/videos/search`
- **License Name:** Pexels License
- **License URL:** [https://www.pexels.com/license/](https://www.pexels.com/license/)
- **Commercial Use:** Permitted (free for commercial and personal use)
- **Attribution Requirements:** Attribution is not required but appreciated (`Video by [Creator] on Pexels`)
- **Modification:** Modification and editing into new video works is permitted.
- **Rights Verification Status:** Verified via Pexels API terms.

### B. Pixabay Stock Video API
- **Provider:** Pixabay / Canva
- **API Endpoint:** `https://pixabay.com/api/videos/`
- **License Name:** Pixabay Content License
- **License URL:** [https://pixabay.com/service/license-summary/](https://pixabay.com/service/license-summary/)
- **Commercial Use:** Permitted across digital media, social networks, and broadcasts.
- **Attribution Requirements:** Not legally required.
- **Rights Verification Status:** Verified via Pixabay API terms.

### C. IncuBrix Procedural Fallback Engine
- **Provider:** Local Synthetic Engine (Pillow + FFmpeg `lavfi` / `zoompan`)
- **License Name:** IncuBrix Fallback Visual License
- **License URL:** `https://incubrix.internal/licenses/fallback`
- **Commercial Use:** Test and development environments only.
- **Attribution:** Generated by IncuBrix Procedural Engine (Local Fallback).
- **Rights Verification Status:** 100% verified (locally synthesized without external intellectual property).
